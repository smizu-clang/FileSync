# FileSync
File Syncing Tool　ファイル同期ツール

ローカルのフォルダ間で、新規・変更ファイルを同期先へコピーするシンプルなCLIです。
Qt Widgets を使った C++17 のデスクトップアプリです。

## 使い方

## ビルド

```sh
cmake -S . -B build
cmake --build build
```

## 同期機能

- 複数の同期設定を保存し、手動または定期的に実行
- 片方向バックアップと、更新日時を使った双方向同期
- 下位フォルダ、拡張子フィルター、ミラー削除を設定可能
- ミラー削除は同期開始前に確認
- 実行ログを画面に表示
